# 分析节命题骨架（2026-07-16 草稿）

记号：学生 s 在概念 c 上的训练观测数 n（=`student_concept_count`），答对数 k，
概念先验率 p̄_c（经验贝叶斯收缩目标），证据后验 m̂ = (k + p̄_c)/(n + 1)，
可靠性 r = n/(n+1)。锚定通道权重 w_j ≥ 0（softplus 参数化）。

## 命题 1（标签翻转不变性 / 防泄漏，M1）

**陈述**：对任一训练样本 i = (s, e, y)，模型前向为其构造的全部输入特征
φ_i（两通道证据、其图传播像、初始状态注入）关于自身标签 y 恒定：
∂φ_i/∂y ≡ 0，且翻转 y 后 φ_i 逐位不变。

**证明骨架**：φ_i 只消费五类统计量（学生-概念 count/correct/residual、概念总量、全局总量），
训练前向对每一类都精确减除第 i 行的贡献（label、计数、残差同时减；
`_build_response_evidence` 的 LOO 分支）；传播通道是 LOO 调整后向量的线性映射
（行随机矩阵左乘），线性保持不变性。∎

**实证**：翻转任意训练行标签，其自身 logit 逐位不变（smoke_label_isolation 已验证，
论文升级为 N 行批量翻转实验）；对照：把标签统计直接并入输入的设计（ORCDF 类）无此性质。

## 命题 2（证据单调性，M2）

**陈述**：对任一 Q 相关概念 c 的任一证据通道值 e，∂p/∂e ≥ 0——
证据增加永不降低预测答对概率。

**证明**：p = σ(a(θ_e − b))，a = softplus(·)+ε > 0；θ_e 是 θ_c 的 Q-mask 均值
（系数 1/|Q| > 0）；∂θ_c/∂e = softplus(w) ≥ 0。非负因子链乘，σ 单调。∎

**对照**：NCDM 的单调性是训练时的权重约束假设；此处是构造保证，与训练无关。

## 命题 3（泄漏偏差定理，A1）★分析节主定理

**陈述**：若把当前样本标签 y 计入其自身证据（self-leak），后验变为
m̂′ = (k + y + p̄_c)/(n + 2)，则

  **Δ = m̂′ − m̂ = (y − m̂)/(n + 2)。**

即泄漏把统计量朝标签方向拉动，幅度与证据计数成反比。

**推论 1（零证据极限）**：n = 0 时 m̂′ = (y + p̄_c)/2，统计量在冷样本内
以 1/2 的间隔完全分离 y=1 与 y=0 → 零证据行占比 →100% 时，泄漏统计量的
排序 AUC → 1。

**推论 2（corpus-leak 同阶）**：先建统计后划分（含验证行自身）的经典错误
含 self-leak 为主导项，同一结论成立。

**实证验证（S3 表，零参数统计量）**：junyi 零证据占比 100% → 泄漏 AUC = **1.0000**
（推论 1 精确命中）；moocradar 26% → 0.9875；xes3g5m 44% → 0.9765；
assist_17 6.9%（n̄≈2.7）→ 0.8380；虚高幅度与平均证据计数反相关，与 Δ ∝ 1/(n+2) 一致。

**设计含义**：精确 LOO 恰好消去 Δ 项（命题 1），是消除该偏差的充分条件。

## 命题 4（充分统计分解，N2）

**陈述**：设 (s,c) 的作答服从参数 m_sc 的伯努利模型，则 (n, k) 是 m_sc 的
充分统计量（因子分解定理）。推论：任何只使用同概念作答数据的预测器，其
可达性能以闭式证据下限为界；模型实测超出下限的部分只能来自跨概念结构
（概念图 + 状态编码）。

**实证（性能可归因分解表，test 口径）**：

| 数据集 | 闭式下限(同概念充分统计) | 模型 | 跨概念结构增量 |
|---|---:|---:|---:|
| assist_17 | ~0.762 | 0.789 | +0.027 |
| junyi | ~0.792 | 0.831 | +0.039 |
| nips34 | ~0.782 | 0.792 | +0.010 |
| ednet | ~0.744 | 0.749 | +0.005 |
| moocradar | ~0.869 | 0.934 | +0.065 |
| xes3g5m | ~0.743 | 0.800 | +0.057 |

（下限取 S2 探针 prop+item 列的 valid 值，正式表需统一到 test 口径重算。）

## 附：多跳传播的负结果（A3，如实呈报）

显式 2-hop 锚定通道在全部五个受测数据集上与 1-hop 持平（±0.0002）——纯实验负结果。
实测 λ₂（学习后的平均关系矩阵）：assist_17 0.51、xes3g5m 0.80、nips34 0.95、moocradar 0.9999。
前三者可用快混合解释（两跳已近平稳、信息同质化）；moocradar λ₂≈1（强社区结构）却同样无增益，
说明"混合速度"不是唯一机制。**论文只报实验事实 + λ₂ 作描述性统计，不做统一理论宣称。**
